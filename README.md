# Zombie Survival — Game Vision

โปรเจกต์เอกสารใหม่สำหรับเกมอินดี้ Steam แบบ Single-player Zombie Survival Tactical Deckbuilding Roguelite ชื่อนี้เป็นชื่ออธิบายโปรเจกต์ ไม่ใช่ชื่อเกมที่อนุมัติแล้ว

**Milestone: M0.1 — Game Vision | เอกสารพร้อมตรวจทาน ยังไม่ใช่การอนุมัติ Game Design หรือ Production Plan**

## เอกสาร

- [GAME_VISION.md](GAME_VISION.md) — วิสัยทัศน์ ประสบการณ์ผู้เล่น ขอบเขต และคำถามเปิด
- [DECISION_LOG.md](DECISION_LOG.md) — การตัดสินใจ สถานะ ที่มา และการแก้ความเข้าใจเดิม
- [MILESTONES.md](MILESTONES.md) — ขอบเขต M0.1 และลำดับงานถัดไปที่เสนอไว้
- [ACCEPTANCE_CRITERIA.md](ACCEPTANCE_CRITERIA.md) — เกณฑ์ตรวจรับเอกสารและประตูอนุมัติงานถัดไป

## วิธีอ่านสถานะ

- **CONFIRMED**: ยืนยันในคำสั่งผู้ใช้หรือบทสนทนาที่ตรวจสอบได้
- **PROPOSED**: ข้อเสนอ ยังไม่อนุมัติ ห้ามนำไปถือเป็นข้อกำหนด
- **UNDECIDED**: ยังไม่มีข้อยุติ ต้องออกแบบหรือตัดสินใจภายหลัง

คำว่า Roguelite ในคำอธิบายเกมไม่ได้ยืนยันระบบอัปเกรดถาวรระหว่าง Run; Roguelike เทียบกับ Roguelite progression ยังรอ Playtest
